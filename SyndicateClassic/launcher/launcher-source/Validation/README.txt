The preserved regression test source covers UI resources/controls, game modes, database configuration, and isolated updater transactions. It is saved as .cs.txt so it is not included in the launcher build. To run, copy to a separate net8.0-windows executable test project with UseWPF=true and a reference to the built SyndicateLauncher.dll; update fixture/resource paths for your workspace. It does not automate authentication, show the launcher, or execute the inert Node test payload.
